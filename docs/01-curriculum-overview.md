# Expo完全ハンズオン教材：健康管理アプリ（Wellness Tracker）を作ろう

## 🎯 この教材について

React経験者がスマホアプリ開発に挑戦するための実践的なハンズオン教材です。
シンプルな状態から始めて、段階的にライブラリを追加しながら、**実用的な健康管理アプリ**を完成させます。

### 完成するアプリの機能
- 📝 毎日の体重・体調記録
- 📊 データのグラフ表示
- 📸 食事写真の記録
- 🚶 歩数カウンター
- 📍 ウォーキングルートの記録
- 💓 Bluetooth心拍計との連携
- 🔔 リマインダー通知
- ☁️ クラウド同期

## 📖 技術解説の構成

各ステップでは以下の図解と解説を含みます：

```
┌─────────────────────────────────────────┐
│         あなたが書くコード (JSX)          │
├─────────────────────────────────────────┤
│         React Core (仮想DOM)            │
├─────────────────────────────────────────┤
│       React Native (Bridge)             │
├─────────────────────────────────────────┤
│    Expo SDK (ネイティブモジュール)        │
├─────────────────────────────────────────┤
│    iOS/Android Native APIs              │
└─────────────────────────────────────────┘
```

### 各ステップで解説する内容
1. **この機能が何をするか**（ユーザー視点）
2. **技術的にどう動くか**（レイヤー構造）
3. **React Webとの違い**
4. **iOS/Androidの違い**
5. **他の選択肢との比較**（必要に応じて）

```
│   ├── components/        # 再利用可能なコンポーネント

│   ├── services/          # API通信など
│   ├── store/             # 状態管理
│   ├── utils/             # ユーティリティ関数
│   └── types/             # TypeScript型定義
├── assets/                # 画像・フォントなど
├── hooks/                 # カスタムHooks
├── constants/             # 定数定義
└── app.json               # Expo設定
```
